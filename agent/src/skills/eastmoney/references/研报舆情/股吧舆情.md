## 股吧舆情（A 股社媒情绪）

工具：`get_a_share_social_sentiment`（`src.tools.a_share_social_sentiment_tool.AShareSocialSentimentTool`）
描述：东方财富股吧（guba）个股帖子列表元数据采集，免鉴权、按源 IP 限流（经 `eastmoney` 节流 bucket）。返回原始帖子元数据（标题/作者/发布时间/阅读数/评论数/链接），**不做情绪打分**——打分由 `social_analyst` agent 调 LLM 完成（与 event-driven skill 的"采集原始、上游打分"范式一致）。
市场：仅 A 股（.SH / .SZ / .BJ）。
限速：经 `eastmoney` bucket（与资金流向/龙虎榜/研报等共享节流）。

<br>

**端点**

| 上游 | 端点 URL |
| ---- | -------- |
| 股吧帖子列表 | `https://guba.eastmoney.com/list,<code>.html`（HTML 列表页，如 600519 → `list,600519.html`） |

> 股吧历史上有 JSON 接口（`gubaapi.eastmoney.com` / `guba.eastmoney.com/interface/GetData`），但端点多次变动、稳定性差。本工具采用 HTML 列表页（最稳定公开入口）+ 正则解析，与 stock_news_tool 的降级策略一致：失败返回 `{"ok": false, "error": ...}`，不 raise。

<br>

**输入参数（工具入参）**

名称 | 类型 | 必选 | 描述
---- | ---- | ---- | ----
code | str | Y | A 股 symbol，如 `600519.SH` / `000001.SZ` / `830799.BJ`。仅 SH/SZ/BJ 后缀。
limit | int | N | 返回帖子数上限（1–100，默认 50）。
source | str | N | 社媒源，目前仅支持 `guba`（默认）。

<br>

**返回字段**

帖子记录（`data.posts[]`）：

字段 | 描述
---- | ----
title | 帖子标题（裁剪至 120 字符）
author | 发帖人昵称
published | 发布时间
read_count | 阅读数（热度代理）
comment_count | 评论数（参与度代理）
url | 帖子链接（`https://guba.eastmoney.com/news,<code>,<id>.html`）

信封：`{"ok": true, "market": "a_share", "source": "guba", "data": {"code", "secid", "posts": [...]}}`。secid 为东财内部寻址（SH=1.x / SZ·BJ=0.x）。

<br>

**调用范例**

```python
from src.tools.a_share_social_sentiment_tool import AShareSocialSentimentTool

# 茅台股吧最近 50 条帖子元数据
print(AShareSocialSentimentTool().execute(code="600519.SH", limit=50))
# 平安银行股吧
print(AShareSocialSentimentTool().execute(code="000001.SZ"))
```

<br>

**下游用法**

采集到的原始帖子元数据交由 `social_analyst` agent：
1. LLM 打分（首选，输出 `-1.0..1.0`）或规则词典兜底
2. 聚合为热度指数 / 看多比例 / 新人指数 / KOL 一致性
3. 映射到 `-100..+100` 综合情绪分

详见 `social-media-intelligence` skill。
